Azeium 2.4.1 — Minecraft Java 1.21.11

INSTALL
Use Java 21, Fabric Loader 0.19.3+ and Fabric API for Minecraft 1.21.11.
Remove old Azeium/spear-control JARs, then put azeium-2.4.1-mc1.21.11.jar in this profile's mods folder.
Press Right Shift (or your saved menu key).

STARTUP FIX
Restoring a saved keyboard spear shortcut no longer resolves its key name before
GLFW initializes. The earlier lookup queued GLFW_NOT_INITIALIZED and crashed
Minecraft during graphics startup. This exact failure was reproduced with 2.4.0
and a saved G bind; the fixed production JAR starts with that same configuration.
Keep your existing azeium.json settings; no reset is needed.

NEW DESIGN AND CONTROLS
The entire UI shares satin pastel gradients, rounded glass panels, smooth hover
states, Allura cursive headings and readable Open Sans setting labels.
Both fonts are licensed and bundled for offline use.
Performance HUD shows actual FPS and server-reported ping without extra probes.
It has an independent toggle and saved module keybind and starts OFF.
Client settings includes Disable all modules. There are fifteen modules across
two sidebar pages. Headers remain draggable and movement works while menus open.

Auto Mace always uses Smash. Enable it; during a valid falling entity attack,
it selects your hotbar mace for that hit, then returns to the previous slot.
Cancelled attacks return too. Grounded/rising/short falls keep their held item.
Reach cycles Vanilla (default) and 3–6 blocks in half-block steps.
This controls local eligibility for an already selected crosshair entity.
It does not extend crosshair picking or server permissions; distant hits can
be rejected by the server. No guarantee of bypassing anticheat is made.

Spear's Quick-lunge key accepts keyboard keys and mouse buttons 1–8.
Click that setting, then press the desired key or mouse button. Escape cancels;
Delete clears. Preferences persist. One press swaps to a hotbar spear, performs
one normal jab and returns to the original slot. Holding does not auto-repeat.
The shortcut works with Spear OFF; vanilla cooldowns still apply in that case.
The module's regular Keybind still toggles cooldown-removal controls separately.
Menus, lost focus, death, disconnect and item use prevent gameplay shortcuts.
Actual lunges require a Lunge enchanted spear and normal vanilla conditions.

DOWNLOAD WEBSITE
Extract the ready ZIP and open index.html in a browser. Its only visible control
is Download. It works offline and saves a ZIP with the JAR, source ZIP and README.
If a viewer displays HTML code, save it as an .html file and open it in a browser.

SOURCE
Extract azeium-2.4.1-source.zip. Build with Java 21: ./gradlew build (Windows: gradlew.bat build).
First builds need Minecraft/Fabric dependencies. Read README.md for all modules.

VALIDATION
24 unit tests passed; transformed client runtime checks passed, including mouse
capture, module-OFF spear action, same-click Smash, slot restoration, cancelled
attacks, manual slot ownership and reach boundaries. 300 GUI ticks rendered.
Production JAR startup is checked separately. No full Dawn modpack, authenticated
world or live multiplayer anticheat compatibility is claimed.
