# Azeium 2.3.0

Minecraft Java 1.21.11 · Fabric Loader 0.19.3+ · Java 21 · Fabric API.

- [Release downloads: JAR, source, README and offline website ZIP](https://github.com/azesociety/my-codings-/releases/tag/v2.3.0)
- [Download the mod JAR](https://github.com/azesociety/my-codings-/raw/refs/heads/main/azeium-2.3.0-mc1.21.11.jar)
- [Download the source ZIP](https://github.com/azesociety/my-codings-/raw/refs/heads/main/azeium-2.3.0-source.zip)
- [Browse the source project](lunge-test-client/)
- [Installation and controls](AZEIUM-README.md)

Replace the older Azeium JAR in your instance's mods folder. Build the source
with Java 21 using `gradlew.bat build` (Windows) or `./gradlew build` (Linux/macOS)
inside `lunge-test-client`. The first build downloads dependencies.

New: fixed Smash Auto Mace with original-slot restoration, optional local
3–6 block eligibility, and a saved keyboard/mouse spear shortcut that works
with the Spear module OFF. Server rules still decide whether distant hits land.
Forward lunges require the Lunge enchantment and normal vanilla conditions.
